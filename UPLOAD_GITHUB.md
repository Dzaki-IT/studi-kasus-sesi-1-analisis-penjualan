# Panduan Upload GitHub (ringkas)

1. Login ke https://github.com.
2. Klik `+` → `New repository`.
3. Isi nama, misalnya `analisis-penjualan-toko`; pilih `Public` jika perlu diperiksa dosen.
4. Jika memakai upload manual, buat repository kosong (jangan centang README karena proyek ini sudah memiliki README).
5. Pada halaman repository pilih `Add file` → `Upload files`.
6. Buka folder proyek di komputer dan seret isi folder proyek (termasuk `README.md`, `data`, `src`, `tests`, `requirements.txt`, `.gitignore`) ke halaman upload. Jangan unggah folder `.venv`.
7. Isi pesan commit, misalnya `Add session 1 sales analysis project`, lalu klik `Commit changes`.
8. Buka halaman repository dan pastikan README tampil serta file-file penting terlihat.
9. Jalankan kode dan pengujian di komputer terlebih dahulu sebelum menyatakan proyek berhasil.

Catatan: folder `outputs` bisa diunggah setelah program dijalankan jika ingin menyertakan hasil grafik dan tabel sebagai bukti. Jangan mengunggah informasi rahasia.
